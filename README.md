# でかプデイリーシャルベ通知bot

VRChatのログファイルを監視し、デイリーシャルベの情報をDiscordに自動通知するBotです。

## 概要

VRChatのログ（`output_log_*.txt`）に出力される以下のような行を検出し、シャルベ名と効果をDiscordチャンネルへ通知します。

```text
[DailySpecialBallManager] Day XXXXX: Special balls are 5, 15, 6
```

上の例だと、紫・草原・白の3種のボールが今日のデイリーシャルベとして通知されます。

## Discord コマンド

| コマンド                                            | 説明                                                   |
| --------------------------------------------------- | ------------------------------------------------------ |
| `/setchannel [lang:ja\|en]`                         | このチャンネルを通知先に設定する（`lang`省略時は`ja`） |
| `/unsetchannel`                                     | このチャンネルの通知設定を解除する                     |
| `/setmentionrole role:<Role>`                       | 通知時にメンションするロールを設定する                 |
| `/unsetmentionrole`                                 | メンションロール設定を解除する                         |
| `/finddaily color1:<色> [color2] [color3] [color4]` | 指定した色を全て含むデイリーを検索する                 |

## 通知ロジック

- VRChatの`[DailySpecialBallManager] Day N: Special balls are ...`行を監視
- 直近の`(Day, balls)`と比較し、Dayが変わったまたは同Day内でballsが変わった場合のみ通知
