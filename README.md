# でかプデイリーシャルベ通知bot

VRChatのログファイルを監視し、**デイリーシャルベ**の情報をDiscordに自動通知するBotです。

## 概要

VRChatのログ（`output_log_*.txt`）に出力される以下のような行を検出し、各ボールの名前と効果を Discord チャンネルへ送信します。

```text
[DailySpecialBallManager] Day XXXXX: Special balls are 5, 15, 6
```

上の例だと、**紫・草原・白** の 3 種のボールが今日のスペシャルボールとして通知されます。

## 対応ボール一覧

| ID | 色 | 効果 |
| -- | -- | ---- |
| 1 | 橙 | 連チャンした後に別のボールに変わるよ |
| 2 | 緑 | ルーレットフィーバーを回すよ |
| 4 | ピンク | ボールをさらに増やすよ |
| 5 | 紫 | プッシャー台を平らにしてボールを増やすよ |
| 6 | 白 | 多めにメダルを出すよ |
| 7 | 水色 | シャルべチャンスの抽選ボールを出すよ |
| 8 | 灰桜 | シャルべチャンスで1マス進むよ |
| 9 | 群青 | シャルベJPプログレッシブカウンターを増やすよ |
| 10 | 赤 | 連チャンした後に別のボールに変わるよ |
| 11 | クリーム | シャルべチャンスの倍率を上げるよ |
| 12 | ミント | 強い抽選ボールを出すことがあるよ |
| 13 | ピーチ | SPメダルを出すよ |
| 14 | 星空 | 時々同じボールを2つ出すよ |
| 15 | 草原 | パレッタチャンスの倍率を上げるよ |
| 16 | 黒 | たまにレインボーシャルべを出すよ |
| 17 | 黄 | パレッタチャンスを早く回すよ |
| 18 | ラベンダー | パレッタJPプログレッシブカウンターを増やすよ |
| 19 | ライム | メダル投入量を一時的に増やすよ |

## Discord コマンド

| コマンド | 説明 |
| -------- | ---- |
| `/setchannel [lang:ja\|en]` | このチャンネルを通知先に設定する（`lang` 省略時は `ja`） |
| `/unsetchannel` | このチャンネルの通知設定を解除する |
